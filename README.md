## 📌 Project Overview

**WayRunning**는 러닝 과정에서 발생하는 데이터를 실시간으로 수집하고,
사용자의 운동 기록을 분석하여 더 효율적인 러닝 경험을 제공하는
스마트 러닝 어플리케이션입니다.

본 프로젝트는 **2026 임베디드 소프트웨어 경진대회 출품작**으로,
Flutter 기반 Android 어플리케이션과 Arduino 기반 센서 시스템을 연동하여 개발되었습니다.

실 기기에서 사용할 수 있는 apk 설치 파일은 app\build\app\outputs\flutter-apk\app-realease.apk 입니다

## ✨ Key Features

| 기능 | 설명 |
|---|---|
| 🏃 실시간 러닝 측정 | 러닝 중 거리, 시간, 가속도, 충격량 데이터 측정 |
